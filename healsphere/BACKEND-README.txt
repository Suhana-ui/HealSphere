HealSphere BACKEND files (Spring Boot, JPA/H2, REST API, tests, pom.xml).
Extract the frontend zip into the same folder so the pages and CSS/JS merge into src/main/resources.
Without the frontend files the API works (/api/...) but the web pages will not.
Run: open pom.xml in IntelliJ, run HealsphereApplication, visit http://localhost:8080/
